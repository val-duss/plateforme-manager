Utilisation recommandée : WSL

Placez demarrer-application.sh et mettre-a-jour-et-rebuild.sh à la racine du dépôt cloné, à côté de docker-compose.yml (ils y sont déjà si vous avez cloné le dépôt Git). Depuis un terminal WSL, dans ce dossier : 

chmod +x *.sh
./demarrer-application.sh

Prérequis dans la distribution WSL : Docker (ou l'intégration WSL de Docker Desktop activée) et Git.

Double-clic depuis Windows

demarrer-application.bat et mettre-a-jour-et-rebuild.bat font la même chose en un double-clic : ils délèguent automatiquement à WSL et exécutent le script .sh correspondant, sans nécessiter Git ou Docker installés côté Windows. Seul WSL doit être installé (wsl --install depuis une invite de commandes administrateur si besoin).
